# RayTube for Meta Ray-Ban Display

RayTube is a lightweight YouTube player UI designed for Meta Ray-Ban Display glasses.

## Features

- Direct playback from a YouTube URL or video ID
- YouTube IFrame Player API
- D-pad / Neural Band friendly navigation
- Play/pause, ±10 s seek, speed, mute
- Recents and favorites stored locally
- Optional YouTube Data API v3 search
- Deep links with `?v=VIDEO_ID`
- Additive-display-friendly dark UI

## Notes

RayTube embeds YouTube using Google's official IFrame Player API. Playback availability still depends on the video's embedding, sign-in, age, and regional restrictions.
