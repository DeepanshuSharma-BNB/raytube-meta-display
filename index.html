About this interface

This is an unofficial glasses front end backed by YouTube's official APIs. It does not copy or iframe the full youtube.com website. Home uses YouTube's Most Popular chart because the public API does not expose the personalized youtube.com Home feed.

Neural Band navigation uses the standard Arrow key + Enter events exposed by Meta Web Apps. Text fields use Meta's normal on-glasses text composer.
